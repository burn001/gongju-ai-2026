1Claude Code 설치

필요한 것 — Claude 유료 구독(Pro · Max · Team · Enterprise 등) 또는 Console 계정(API, 선불 크레딧). 무료 요금제에는 없습니다. Windows 10(1809 이후) · macOS 13 이후 · 메모리 4GB 이상 · 인터넷 연결.

Windows는 PowerShell, Mac은 터미널을 열고 한 줄을 붙여 넣은 뒤 Enter를 누릅니다. 설치가 끝나면 창을 닫고 새로 엽니다.

irm https://claude.ai/install.ps1 | iex curl -fsSL https://claude.ai/install.sh | bash

(위는 Windows PowerShell, 아래는 macOS · Linux · WSL.) 다른 방법: winget install Anthropic.ClaudeCode · brew install --cask claude-code. Windows는 Git for Windows를 깔아 두면 좋습니다(선택).

출처: code.claude.com/docs/en/setup · 시작 안내

2첫 실행 · 로그인 · 확인

  1. 설치 확인 — 버전 번호가 나오면 성공입니다.claude --version
  2. 작업 폴더에서 실행 — 실습용 빈 폴더를 하나 만들어 두세요.cd 작업폴더claude
  3. 처음 한 번 로그인 — 브라우저가 열리면 구독 계정으로 로그인합니다. 계정을 바꿀 때는 Claude Code 안에서 /login 을 입력합니다.
  4. 문제가 있으면 점검 — 설치 상태·설정 오류를 보여 줍니다.claude doctor

폴더 = 사무실. 에이전트는 실행한 폴더 안의 파일을 읽고 씁니다. 중요한 자료가 있는 폴더가 아니라 실습용 폴더에서 시작하세요.

3바깥 도구 연결 — MCP 서버와 스킬

보고서 실습에서 AI는 한글 문서를 읽고 국가통계를 조회합니다. 이런 바깥 도구는 MCP 서버로 연결합니다. 한 줄이면 됩니다.

문서 읽기 kordoc — 한글 HWP · HWPX · PDF를 마크다운으로 바꿔 읽습니다.

claude mcp add kordoc -- npx -y kordoc mcp

등록 없이 파일 하나만 바꿀 때:

npx kordoc 보고서.hwpx -o 보고서.md

국가통계 KOSIS korean-stats — 원격 서버, 키 없이 쓰는 방법:

claude mcp add --transport http korean-stats https://mcp.gomdori.app/stats

내 KOSIS 인증키로 내 PC에서 돌리는 방법(키 필요, 4번 참고):

claude mcp add korean-stats -e KOSIS_API_KEY=내키 -- cmd /c npx -y korean-stats-mcp claude mcp add korean-stats -e KOSIS_API_KEY=내키 -- npx -y korean-stats-mcp

(위는 Windows, 아래는 Mac.) 확인: claude mcp list 또는 Claude Code 안에서 /mcp. npx를 쓰려면 Node.js 20 이상이 필요합니다(nodejs.org, LTS).

스킬은 설치 명령이 없습니다. SKILL.md가 든 폴더를 아래 위치에 넣으면 다음 대화부터 씁니다. (MCP = 도구를 연결 · 스킬 = 방법을 적은 매뉴얼)

~/.claude/skills/<이름>/ (내 PC 전체) .claude/skills/<이름>/ (이 프로젝트만)

출처: mcp · skills · kordoc · korean-stats-mcp

4API 키 받기 — 비밀번호처럼 다룹니다

국가통계 KOSIS 인증키 (kosis.kr/openapi)

  1. KOSIS 공유서비스 OpenAPI 누리집에서 회원가입 · 로그인.
  2. 위쪽 '활용신청'에서 OPEN API 인증키 신청.
  3. 받은 인증키를 복사해 둡니다. (원격 korean-stats 서버는 키 없이도 씁니다.)

공공데이터포털 키 (data.go.kr)

  1. 공공데이터포털에서 회원가입 · 로그인.
  2. 쓸 API를 데이터목록에서 찾아 활용신청.
  3. 승인 뒤 인증키 발급(자동승인은 바로, 심의승인은 보통 2～3일).
키는 비밀번호입니다
  • 대화창 · 공개 파일 · 스킬 폴더에 붙여 넣지 않습니다.
  • 환경변수나 설정 파일에 넣습니다.
  • 새어 나갔으면 바로 다시 발급받습니다.

환경변수 예 — Windows(PowerShell):

setx KOSIS_API_KEY "발급받은_키"

macOS · Linux (~/.zshrc 등에):

export KOSIS_API_KEY="발급받은_키"

출처: kosis.kr/openapi 이용절차 · data.go.kr 오픈API 활용 안내 · korean-stats-mcp 설치 안내(2026. 11. 16. 확인). 화면 이름은 바뀔 수 있습니다.

OpenAI Codex CLI로 하려면

Claude Code 대신 Codex를 써도 지시문은 같습니다. 설치와 로그인:

npm install -g @openai/codex curl -fsSL https://chatgpt.com/codex/install.sh | sh

(위는 npm, 아래는 공식 안내의 macOS · Linux 설치 줄. Windows 설치는 공식 안내를 따르세요.) 설치 뒤 작업 폴더에서 codex 를 입력하고 Sign in with ChatGPT로 로그인합니다. 창을 닫았다면 codex resume 으로 이어 가고, 웹 검색이 필요하면 codex --search 로 켭니다(공식 안내 2026. 11. 17. 확인).

MCP 등록은 아래 줄을 쓰되 확인 필요 — 공식 안내에서 codex mcp add 의 형식을 직접 확인하지 못했습니다. 원격 korean-stats 서버를 Codex에 연결하는 방법도 확인 필요입니다.

실습할 때마다
  1. 문서 폴더에 AI실습 폴더를 만들고, 그 안에 실습마다 빈 폴더를 하나씩 만듭니다(예: 1_보고서).
  2. 그 폴더를 파일 탐색기에서 열고 빈 곳을 오른쪽 클릭 → 터미널에서 열기(Mac은 폴더를 터미널 아이콘에 끌어다 놓기).
  3. claude 또는 codex 를 입력해 실행하고, 아래 지시문을 복사해 붙여 넣습니다. AI는 이 폴더 안에서만 일합니다.
  4. AI가 파일을 만들거나 명령을 실행하려 하면 허락을 묻습니다. 무엇을 하려는지 읽어 보고 허락하세요.
  5. 단계가 여러 개면 ①이 끝나 AI가 멈춘 뒤 같은 창에 ②를 붙여 넣습니다. 창을 닫았다면 같은 폴더에서 claude --continue(Codex는 codex resume)로 이어 갑니다.
  6. 결과는 폴더 안 out 폴더에 생깁니다. html 파일은 두 번 눌러 브라우저로 엽니다.
공통 규칙(선택) — 실습 폴더에 저장해 두면 AI가 매번 읽습니다

Claude Code는 CLAUDE.md, Codex는 AGENTS.md 라는 이름의 파일로 실습 폴더에 저장하세요. 첫 지시문 앞에 붙여 넣어도 됩니다.

공통 규칙
이 폴더에서 일할 때 지킬 것:
- 이 폴더 밖의 파일은 만들거나 고치지 않습니다.
- 무거운 조사·글쓰기는 팀원(서브에이전트)에게 나눠 맡기고, 동시에 할 수 있는 일은 동시에 합니다. 결과는 파일로 받습니다.
- 숫자·사실은 직접 확인한 값만 쓰고 출처를 답니다. 확인하지 못한 값은 지어내지 말고 "확인 필요"로 둡니다.
- 개인정보(이름·연락처·주소)는 모으지도 쓰지도 않습니다.
- 중간 말과 마지막 답은 짧고 쉬운 한국어 존댓말로 씁니다.
꼭 지켜 주세요
  • 요금 — 두 도구 모두 유료 요금제나 사용량 요금이 듭니다. 오래 돌리거나 많이 시키면 사용 한도가 빨리 찹니다. 실습 하나씩 짧게 해 보세요.
  • 개인정보 — 내가 넣은 글과 파일은 AI 회사 서버로 보내집니다. 주민등록번호·계좌·비밀번호, 남의 이름·연락처는 넣지 마세요.
  • 확인은 사람이 — AI 결과는 초안입니다. 숫자·날짜·공고·시설 정보는 원문을 열어 다시 확인하고, 고르고 정하는 일은 사람이 하세요.
  • 사이트 예의 — 남의 사이트를 짧은 시간에 많이 열게 하지 마세요. 로그인이 필요한 곳은 맡기지 않습니다.

오늘 강의실에서는 채팅과 투표로 입력을 모으고, 미리 만들어 둔 도구로 시간을 줄였습니다. 아래 지시문은 그런 장치 없이 혼자 돌아가도록 고쳐 쓴 것이라, 결과 모양은 오늘과 조금 다를 수 있습니다. 팀원(서브에이전트)을 나눠 쓰는 방식은 Claude Code 기준입니다.

① 주제 정리 — 후보 3개 고르기
아래는 제가 보고서로 알고 싶은 것들을 적은 메모입니다(예시 — 내 메모로 바꿔도 됩니다).
- 우리 시에서 다시 일하려는 여성은 얼마나 될까

- 여성 창업 지원 제도가 있는지
- 30～40대 여성 고용률이 궁금해요

비슷한 것끼리 묶어 몇 건인지 세고, 하기 어려운 것(개인정보·로그인 필요·불법·너무 큰 주제)은 이유를 한 줄 붙여 빼 주세요.

기본 틀:

② 자료 담당 — 정부·기관·언론 자료 4～6건 (가능하면 2024～2026년 자료)
③ 작성·확인 담당 — 두 사람의 결과만 보고 초안을 쓰고, 숫자를 원자료와 대조
통계가 맞지 않는 주제면 ①을 '제도·사례 담당'으로 바꿔 주세요. 아직 조사는 하지 말고 계획만 보여 주고 멈춰 주세요.
③ ⓐ 조사하고 md 보고서 만들기
설계한 대로 팀원들에게 나눠 조사하고, 센터장님 보고용 개조식 보고서를 마크다운(md) 파일로 먼저 만들어 주세요. 한글 파일로 바꾸는 것은 다음 지시에서 합니다.
· ① 통계 담당과 ② 자료 담당은 동시에 일합니다. 결과는 work/stats.md(지표·값·단위·시점·통계표 이름·찾은 곳 주소 표)와 work/web.md(제목·기관·날짜·주소·핵심 1～2줄)에 적어 주세요. 값은 찾은 그대로 옮기고 새로 계산하지 않습니다.
· 둘이 끝나면 ③ 작성·확인 담당이 두 파일만 보고 out/보고서.md(A4 2쪽 안팎)를 씁니다. 틀은 이렇습니다: 제목 → 한두 문장 요약(핵심 숫자 1～2개) → 추진 배경 → 현황(표 1개: 지표 | 값 | 시점 | 출처) → 사례·정책 동향 → 과제 및 제안 → 참고자료. 항목은 □(1단계)·○(2단계) 목록으로 씁니다.
· 보고서 속 숫자를 하나하나 두 파일과 대조해 work/factcheck.md(문장 속 숫자 · 근거 값 · 일치/불일치/근거 없음)에 남기고, 불일치·근거 없음은 지우거나 "확인 필요"로 고칩니다.
· 모든 숫자 옆에 출처를 달고, 확인하지 못한 값은 지어내지 마세요.
· 끝나면 out/보고서.md 경로와 핵심 숫자 2～3개만 짧게 알려 주고 멈춰 주세요. 한글 파일은 아직 만들지 마세요.
④ ⓑ md 보고서를 한글 파일로 바꾸기
out/보고서.md 를 한글(HWPX) 파일로 바꿔 주세요. 조사와 글쓰기는 다시 하지 않습니다.
· 공개 도구 kordoc으로 바꿉니다: npx -y kordoc@4.24.25 generate out/보고서.md -o out/보고서.hwpx --preset 개조식 --no-toc
· 만든 뒤 npx -y kordoc@4.24.25 validate out/보고서.hwpx 로 구조 검사를 하고 통과했는지 알려 주세요.

· 사이트에 부담 주지 않기: robots.txt가 막은 곳은 건너뛰고, 목록은 출처당 1쪽만, 요청 사이에 몇 초씩 쉬고, 로그인이 필요한 곳은 하지 않기
· 근무지가 ○○시이고 지금 접수 중인 공고만, 모두 합쳐 30～50건이면 충분합니다.
· 공고마다 제목·회사·근무지 주소(아는 만큼)·직무·고용형태·급여·근무시간·마감일·원문 주소·출처를 work/jobs_raw.json 에 모읍니다.
· 담당자 휴대전화·이메일 같은 개인 연락처는 절대 모으지 않고, 지어내지 않습니다.
끝나면 출처별 건수와 뺀 이유만 짧게 알려 주고 멈춰 주세요.
② 정리·점수
② 이어서 같은 공고는 하나로 묶고, 직종을 나누고, 경력단절여성에게 맞는지 점수를 매겨 주세요.
· 같은 회사 + 같은 직무 + 같은 근무지면 같은 공고입니다(같은 매장이라도 근무 시간대·요일·직무가 다르면 다른 공고).
· 마감이 지난 공고와 ○○시 밖 근무는 뺍니다.
· 점수 기준을 먼저 짧게 정해 work/점수기준.md 에 적고(예: 경력 무관·초보 가능, 낮 시간·시간제, 자격 부담, 교육 지원 여부), 공고마다 '적합 / 조건부 / 부적합'과 이유 한 줄을 붙입니다.
· 주소를 지도 좌표로 바꿉니다(무료 지도 검색은 1초에 한 번만). 정확한 주소가 없으면 읍·면·동 중심에 두고 '위치 근사'로 표시합니다.
· 결과는 work/jobs.json. 끝나면 건수만 짧게 알려 주고 멈춰 주세요.
③ 지도 ④ 검수
③ 지도 대시보드 out/jobs_map.html 을 만들어 주세요.
· 지도 위에 공고를 표시하고 직종·적합도로 걸러 볼 수 있게, 공고를 누르면 원문 주소가 나오게
